Instagram Export

I want to get off social media, or at least reduce my presence, and I thought I’d get all my data. This is a post about Instagram.

First I did this: https://help.instagram.com/7130835797039956/

The download is a zip file with supposedly all of your information. It does not provide everything. Some of the data is limited to the previous week, some is limited to when Instagram features came in and out of use.

Should I start with the file named start_here.html? Yes. It provides a good structure for this post as well. I’m going to include all the categories and lots of information in an anonymous way.

Conclusion

This was interesting even though I haven’t used many of the possible Instragram features. I think charts is the best way to show activity. I had planned to show some different pages, but I didn’t, and all the links here are broken. The pages are either not interesting or not anonymous enough.

This might be useful for someone else to look at their Instagram statistics, the code is available on my GitHub. For the sake of presentation I have not included it in this post. (I also couldn’t figure out how to get code folding to work).

Because I have collected the data along the way, I can put it all together. Two charts here, because ‘Not Interested’ dominates the other measures.
