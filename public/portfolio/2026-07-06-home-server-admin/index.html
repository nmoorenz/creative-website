Home Server Admin

Here are some commands and links that have been helpful while setting up a home server.

Apps

https://jellyfin.org
https://immich.app
https://nextcloud.com
https://pi-hole.net

Commands

Lots of output for what drives are currently mounted
mount

Mount paths with options
findmnt

More disk details for partitions with sector, unit, id, size
sudo fdisk -l

Useful to see sizes and percent used for drives: disk free human readable
df -h

Human readable output for disk usage, summarize for a human, for the current folder
du -sh -- *

Mounts and uuid: block id, used in fstab
blkid

What gets mounted at boot - file system table
cat /etc/fstab

Manually mount the drive
sudo mount -t ntfs-3g /dev/sdb1 /media/nathan/Elements

New line in fstab to mount the external drive on startup
UUID=2220418F20416B3D /media/nathan/Elements ntfs-3g rw,auto,user,fmask=0111,dmask=0000 0 0
