I downloaded my old Tumblr posts

I downloaded my old Tumblr posts to create some analysis like I did with my Instagram activity.

https://www.nmoore.nz/portfolio/2026-03-17-insta-export/

The Tumblr export is a zip file with a media folder of images and a posts folder with one HTML file per post. Each post has the image, a caption, a timestamp and the tags.

A Python script turns the HTML into a single posts.csv with post id, timestamp, tags and text. The charts below come from that file.
